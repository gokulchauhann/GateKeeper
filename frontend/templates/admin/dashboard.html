Resource protection

{% if governor_mode == "enforced" %} The Governor is assigning tenant sessions to their cgroups. {% else %} How GateKeeper isolates tenants. In stub mode none of these controls are active. {% endif %}

{{ icon("cpu") }}CPU control

Each plan's CPU quota is written to the tenant cgroup's cpu.max, so the kernel scheduler caps it.

{{ icon("memory") }}Memory usage

Read from memory.current. The plan's limit is applied as memory.high: the kernel slows the tenant down instead of killing a backend.

{{ icon("activity") }}Throttling

Computed from the change in throttled_usec in cpu.stat between two samples.

{{ icon("layers") }}Tenant isolation

Each tenant has its own connection pool, and every backend PID it uses is moved into that tenant's cgroup.
